# tinyseed
TinySeed Bitcoin — cartões imprimíveis (PDF, pronto para impressão) para backup físico da sua seed phrase (BIP39) em papel/cartolina, usando codificação binária. Dois tamanhos (Normal e Bigger, tamanho cartão de crédito) e dois formatos (folha simples e bifold duplex com capa). Alternativa de baixo custo aos backups em metal.
